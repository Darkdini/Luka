# Новая тематика — заметки по референсам

Собираем картину по скриншотам, которые присылает автор. Механики жанра берём,
названия/персонажей/арт/тексты чужой игры НЕ копируем — всё своё.

**Тема:** тёмное городское фэнтези, наше время, ночной готический город.
**Рабочее название:** «Чёрная Луна» (не утверждено).

## 1. Запуск и регистрация (скрины 1–6)
- Заставка 9:16: герой на крыше, ночь, дождь, луна, логотип сверху справа, полоса загрузки внизу с подписью этапа («Инспекция 99%»), ссылки на соглашения внизу.
- Слева сверху мелкие кнопки: поддержка, настройки/починка.
- Во время загрузки — подсказки («Улучшите Стену, чтобы…»).
- Окно «Условия использования»: текст, ссылки на соглашение и политику, «Принять» / «Отказаться». Нам нужно своё (152-ФЗ).
- Выбор фракции: герой во весь рост на тематическом фоне, справа табличка на цепях: название, картинка штаба, «О фракции», «Бонус фракции» (два бонуса по +5%), кнопка «Выбрать». Внизу 4 щита-герба, четвёртая фракция «Скоро».
- 4 фракции: Вампиры (стройка + стрелки), Оборотни (тренировка + быстрые бойцы), Охотники (добыча ресурсов + защита), Маги (исследования + здоровье). У каждой — свой стиль штаба.

## 2. Вступление после выбора (скрины 7–8)
- Слайды 9:16 с текстом внизу, кнопка SKIP сверху справа.
- Город, катастрофа с неба, люди бегут, «Иные» получают силу. (Их лор — метеориты и кристаллы, нам нужен свой: у нас «Чёрная Луна».)

## 3. Первые минуты в квартале (скрины 9–13)
- Квартал в темноте, освещён только участок у штаба; остальное постепенно открывается.
- Наставник фракции: персонаж во весь рост слева, плашка с именем, реплика внизу, «Пропустить». Реплики короткие, с характером. Второй персонаж может вступить в диалог.
- Готовая добыча — крупный светящийся значок над зданием; при сборе иконка летит в верхнюю строку, над зданием «+N».
- Указатель — золотая перчатка-рука с пульсирующим кольцом.
- Расчистка руин/завалов даёт ресурс и освобождает место.
- Задание — одной строкой внизу слева со свитком («Построить 2 фермы»).
- Табличка с цифрой уровня у каждого здания.

## 4. Интерфейс (скрины 9–13)
- Сверху: строка всех ресурсов (у них 6 — нам 4 + премиум).
- Ниже: аватар (полоска здоровья/опыта под ним), кнопка статистики, по центру «Сила» (общая мощь) в золотой рамке, справа премиум-валюта.
- Под аватаром время сервера.
- Слева: кнопка квартала/штаба со счётчиком (0/1).
- Справа вертикально: «Меню», «Герой», «Построить» (с красной меткой).
- Внизу: строка мирового чата (аватар, ник, сообщение), кнопка-замок справа.
- Общая палитра: чёрный, тёмная бронза/золото, приглушённый свет фонарей.

## Решения пока не приняты
- Название игры.
- Набор ресурсов (предложение: еда, эссенция, материалы, деньги + Камни Тьмы).
- Что из старой средневековой версии оставить.
