# Новая тематика — заметки по референсам

Собираем картину по скриншотам, которые присылает автор. Механики жанра берём,
названия/персонажей/арт/тексты чужой игры НЕ копируем — всё своё.

**Тема:** тёмное городское фэнтези, наше время, ночной готический город.
**Рабочее название:** «Чёрная Луна» (не утверждено).

## 1. Запуск и регистрация (скрины 1–6)
- Заставка 9:16: герой на крыше, ночь, дождь, луна, логотип сверху справа, полоса загрузки внизу с подписью этапа («Инспекция 99%»), ссылки на соглашения внизу.
- Слева сверху мелкие кнопки: поддержка, настройки/починка.
- Во время загрузки — подсказки («Улучшите Стену, чтобы…»).
- Окно «Условия использования»: текст, ссылки на соглашение и политику, «Принять» / «Отказаться». Нам нужно своё (152-ФЗ).
- Выбор фракции: герой во весь рост на тематическом фоне, справа табличка на цепях: название, картинка штаба, «О фракции», «Бонус фракции» (два бонуса по +5%), кнопка «Выбрать». Внизу 4 щита-герба, четвёртая фракция «Скоро».
- 4 фракции: Вампиры (стройка + стрелки), Оборотни (тренировка + быстрые бойцы), Охотники (добыча ресурсов + защита), Маги (исследования + здоровье). У каждой — свой стиль штаба.

## 2. Вступление после выбора (скрины 7–8)
- Слайды 9:16 с текстом внизу, кнопка SKIP сверху справа.
- Город, катастрофа с неба, люди бегут, «Иные» получают силу. (Их лор — метеориты и кристаллы, нам нужен свой: у нас «Чёрная Луна».)

## 3. Первые минуты в квартале (скрины 9–13)
- Квартал в темноте, освещён только участок у штаба; остальное постепенно открывается.
- Наставник фракции: персонаж во весь рост слева, плашка с именем, реплика внизу, «Пропустить». Реплики короткие, с характером. Второй персонаж может вступить в диалог.
- Готовая добыча — крупный светящийся значок над зданием; при сборе иконка летит в верхнюю строку, над зданием «+N».
- Указатель — золотая перчатка-рука с пульсирующим кольцом.
- Расчистка руин/завалов даёт ресурс и освобождает место.
- Задание — одной строкой внизу слева со свитком («Построить 2 фермы»).
- Табличка с цифрой уровня у каждого здания.

## 4. Интерфейс (скрины 9–13)
- Сверху: строка всех ресурсов (у них 6 — нам 4 + премиум).
- Ниже: аватар (полоска здоровья/опыта под ним), кнопка статистики, по центру «Сила» (общая мощь) в золотой рамке, справа премиум-валюта.
- Под аватаром время сервера.
- Слева: кнопка квартала/штаба со счётчиком (0/1).
- Справа вертикально: «Меню», «Герой», «Построить» (с красной меткой).
- Внизу: строка мирового чата (аватар, ник, сообщение), кнопка-замок справа.
- Общая палитра: чёрный, тёмная бронза/золото, приглушённый свет фонарей.

## 5. Стройка и задания главы (скрины 14–23)
- Первые здания: ферма (поле с работниками) и мастерская; у каждого — табличка с уровнем «1».
- Над зданием всплывает «+8» с иконкой ресурса, иконка летит к аватару/строке ресурсов. Реплика наставника («Человеческой еды не хватает!») — повод построить ещё ферму.
- Расчистка руин: перчатка указывает на завал → вспышка → вылетают брёвна → завал исчезает, ресурс +.
- Кнопка «Построить» справа подсвечивается кольцом, когда её нужно нажать.
- Меню стройки — нижняя панель: слева вертикальные вкладки категорий с горгульей сверху (экономика, военное, декор), справа горизонтальная лента карточек зданий (картинка на подложке, название, описание, «Построено 1/2»; закрытые — с замком и кнопкой «Перейти», платные «Элитные» здания).
- Сверху флажок «Блокировка положения здания» (защита от случайного перетаскивания).
- Размещение: изометрическая сетка подсвечивается, здание-призрак со стрелками перемещения, кнопки ✖ и ✔ над ним.
- После постройки: фиолетовые лучи/эффект с неба, работники на поле, Сила растёт (+4).
- Задание внизу: когда выполнено — строка становится зелёной, вокруг свитка кольцо и золотой указатель.
- Окно главы (планшет-клипборд): «Глава 1: Название», картинка-баннер, 3–4 задания с наградой ресурсом и кнопками «Забрать» / «Перейти», последнее закрыто замком; внизу «Награда главы» (предметы: ускорения 5 мин / 1 мин, энергия, кристалл) и «Забрать все», «Прогресс главы 1/4».
- Задания главы 1: построить 2 фермы → очистить руины 4 раза → отвоевать статую стража (первый бой).
- Ускорения как предметы (5 мин, 1 мин) — отдельная механика, кроме премиум-валюты.

## 6. Окно главы — поведение, руины, переход к первому бою (скрины 24–32)
- Задание с бегущей строки внизу: при выполнении строка зеленеет, свиток в кольце, указатель-лапа зовёт открыть окно главы.
- Окно главы: «Забрать» у выполненного → строка уезжает вниз со штампом «Получено» (серый оттиск), активные задания поднимаются наверх. Кнопка «Перейти» (синяя) ведёт прямо к цели (камера + перчатка).
- Счётчики (2/4), (0/1) справа над кнопкой; прогресс главы внизу растёт (1/4 → 2/4).
- После получения — ресурс прибавляется в верхней строке (зерно 50K → 52K).
- Руины разные по виду (ограда кладбища, обломки, кусты); при нажатии всплывает табличка-подсказка с лопатой над завалом, затем завал исчезает и ресурс летит вверх (дерево 41K → 49K → 57K). Расчищенное место остаётся пустой землёй под стройку.
- Камера сама подъезжает к следующей цели.
- Цель-бой отмечена на карте красной меткой-капелькой с иконкой врага (капюшон) над объектом («Статуя стража» — круглая разрушенная ротонда).
- Наставник поясняет цель, ключевое слово выделено оранжевым («Статуя стража — источник силы для Фракции»). Наставник может стоять справа.
- Сила не меняется от расчистки, растёт от построек.

## 7. Первый бой — героями, а не войсками (скрины 33–41)
ВАЖНО: это другой тип боя, чем у нас сейчас (высадка войск на базу). Здесь — автобой отрядов героев.
- Окно цели «Уничтожить захватчиков»: бейдж-герб сверху, баннер-картинка, описание («Можете восстановить здание, захваченное врагами, после победы над ними»), «Награды» (опыт героя — золотые звёзды-кубки ×500), кнопка «Задание».
- «Построение героев»: 5 слотов-карт — передний ряд 2, задний ряд 3. Над рядами общая Сила отряда (0 → 2 423 → 3 842). Справа вверху кнопка набора (круг из 5 ячеек). Внизу список героев с вкладками-фильтрами по фракциям (все / вампиры / оборотни / маги / охотники). Карточка героя: портрет, иконка фракции, иконка класса (маг/воин), «Ур. 1». Выбранный — с зелёной галочкой. Кнопки «Бой» и «Описание эффектов». Обучение подсвечивает кольцом, кого ставить.
- Карта героя на позиции: большой портрет, рамка по редкости (золотая/синяя), имя, класс.
- Бой: изометрическая арена (тёмный каменный мост/площадь, золотые узоры, туман, мёртвые деревья). «Раунд: N» сверху. Герои и враги — 3D-модели с полосками HP (с иконкой фракции) и полоской энергии. Враги — оборотни-звери.
- Внизу карточки героев с HP и энергией; когда энергия заполнена — карточка светится, ульта.
- Ульта: крупный портрет героя + название умения («Брызги крови»), вспышка, эффект на земле.
- Новый персонаж-подсказчик в бою (девочка с книгой) поясняет механику, «Пропустить».
- Победа: герой во весь рост на тёплом фоне, огромное «VICTORY», MVP слева сверху (имя, урон и %), награды, «Нажмите на экран, чтобы продолжить», кнопка статистики боя.
- Итого: в игре два слоя — герои (RPG-отряд, автобой по раундам, PvE) и, видимо, войска для карты мира (уточнить по следующим скринам).

## 8. Починка, завершение главы, улучшение главного здания (скрины 42–50)
- Окно здания (полный экран): название «Статуя стража уровня 0», большая картинка здания на размытом фоне города, «Следующий уровень: N» — список эффектов «было → +прибавка» зелёным (Сила +25, сокращение времени постройки +1 мин, здоровье войск). Блок «Требования»: здание нужного уровня / ресурсы «есть/нужно» с зелёными галочками. Внизу две кнопки: зелёная «Починить сейчас / Улучшить» за премиум (💎1) и золотая «Починить / Улучшить» с таймером. Первые постройки длятся секунды.
- Отвоёванное здание сначала «уровня 0» (руины) — его нужно починить.
- Во время стройки: над зданием плашка «↑ 00:00:02» с полосой прогресса, кнопка «Ускорение» рядом; леса вокруг здания (строительные заграждения); название здания плашкой; на зданиях с добычей — значки ресурса (зерно), можно собрать.
- Готово — статуя с горгульей ожила (фиолетовое сияние → новая модель).
- Окно главы, финал: все 4 задания со штампом «Получено» (выполненные съезжают вниз, замок-слот анимированно открывается и выдаёт новое задание «Починить Статую стража»). Награда за задание вылетает карточкой (дерево 1.2K).
- «Забрать все» за главу → экран «Поздравляем!»: предметы в рамках по редкости (фиолетовая/зелёная/золотая), кристалл-рубин ×10, ускорения 5 мин ×30 и 1 мин ×50, энергия ×2, ещё сундук.
- Переход к следующей главе — полноэкранная заставка: «Глава 2 / Обретение формы / Удача на нашей стороне.» поверх атмосферной картинки замка в тумане.
- Главное здание («Городской центр»): эффекты уровня — Сила +500, лимит времени накопления ресурсов (4ч +30мин), защищённые от грабежа ресурсы (30 000 +5 000), лимит героев в отряде кампании, атака войск. Требования: другое здание (статуя ур.1) + ресурсы.
- Счётчик слева «1/1» (главное здание) меняется после постройки.
- Над главным зданием — значок фракции (кубок вампиров) в золотом кольце при улучшении.
- Новое задание внизу: «Улучшить Городской центр до ур. 2».
- Красная метка «1» на «Меню» — что-то новое открылось.
- Предметы-ускорения и «энергия» — отдельный инвентарь.

## 9. Захваченные здания в квартале, бой №2 (скрины 51–59)
- В квартале стоят здания, захваченные врагами: над каждым красная метка-капля с иконкой врага; активная цель — метка в золотом пульсирующем кольце.
- Перед боем — сцена с новыми персонажами-союзниками (у вампиров: Беатрис в короне с бокалом — «Убирайтесь из моей любимой таверны!», Алексия — девочка с книгой: «Это наш человек. Кажется, ему нужна помощь»). Каждый захваченный объект — маленькая история + новый герой/союзник.
- Ресурсы при сборе летят цепочкой иконок (брёвна) от здания к счётчику в верхней строке.
- Над зданиями, которые можно улучшить, — маленькая зелёная стрелка ↑ у таблички уровня.
- Значок сбора ресурса — серый круг-«капля» с иконкой и зелёной полоской заполнения под ним (растёт по мере накопления).
- Бой №2: другая арена (зал замка, колонны, знамёна, статуи), враги — серые оборотни. Появилась кнопка скорости боя «×1» справа.
- Анимации: герой подбегает к врагу, удар с жёлтым дуговым шлейфом, цифра урона «−146» над целью, враг падает (труп остаётся). Полоска HP + жёлтая полоска энергии у каждого. Карточки героев внизу светятся по очереди — чей ход.
- Сверху слева/справа — круглые иконки построения (5 ячеек) своей и вражеской стороны.

## 10. Новый герой за бой, бонус фракции в отряде (скрины 60–68)
- Награда за победу может быть героем (портрет в фиолетовой рамке среди наград). MVP показывает урон и % (530, 75.71%). Сила аккаунта растёт после боя (5 208 → 6 960).
- Отвоёванный объект — таверна; освобождённая героиня (Беатрис) благодарит: «Друзья мои, есть ли для меня приветственная вечеринка?»
- Экран «NEW HERO»: героиня во весь рост на фиолетовом фоне, редкость «Эпич.» (фиолетовый бейдж) + титул «Графиня», имя, герб фракции; три тега-роли с иконками (AoE / Боец / Развитие); описание-лор (родственница главного героя и т.п.); «Нажмите на экран, чтобы продолжить».
- Следующая цель даёт в награду фрагменты героя (портрет-пазл ×2) — герои собираются из осколков.
- Наставник: «Мы получили нового героя. Возьмите его с собой в бой!»
- Построение: перчатка показывает перетащить героя из заднего ряда в передний (drag&drop карт). Рамки по редкости: золотая (легенд.), фиолетовая (эпич.), синяя (редк.).
- Индикатор состава справа вверху: круг из 5 ячеек заполняется гербами фракций — бонус за героев одной фракции (синергия).
- Бой №3: третья арена (тронный зал с красным ковром и свечами). Враги-оборотни; у врага цифра урона красная (−369), кровавые эффекты. Карточки внизу — 3 героя.
- Иконка состава отображается и в бою (слева — наш, справа — враг).

## 11. Войска на карте, алтарь, стена, зоны (скрины 69–78)
- Победа даёт фрагменты героя (пазл ×2) — собирать до полного героя.
- Войска существуют: отдельная сцена — армия идёт по полю к захваченному зданию (вампирши-жнецы с косами, летучие мыши, оборотни-звери, крылатый командир в центре), под каждым юнитом красный круг-маркер. Это, видимо, марш/атака войск (второй слой боя).
- Меню здания по нажатию — круглые кнопки дугой вокруг здания с подписями: «Инфо», «Улучшить», «Грааль», «Алтарь восстановления» (подсвечено), «Снайпер-гастер»… Здание при этом подсвечено зелёным ромбом (можно двигать).
- «Алтарь восстановления»: главный герой парит в кровавом круге без сознания («Владыка Каин упал в обморок. Нужно собрать Зелья восстановления»), полоска из 5 сегментов, «Стоимость следующего лечения: зелье 0/1», кнопка «Вылечить». Сюжетная механика: лечить лидера по шагам — длинная цель.
- Значок-молоток над объектом, который можно починить (ворота/стена).
- «Починка Стены»: окно с картинкой кованых ворот, требования (главное здание ур.1, ресурсы), кнопка «Починить».
- После починки стены — эффект «Зона расчищена» (золотой баннер), открывается новая область квартала: появилась ограда-стена вокруг, трава стала ярче.
- Подписи зданий видны при обзоре: «Таверна героев», «Казарма», «Стена», «Ферма», «Мастерская». Следующая цель — красная метка с иконкой двух пистолетов (вражеский объект другого типа).
- Таверна героев — отвоёванное здание (место призыва героев). Казарма — захвачена, видимо следующая цель.

## 12. Что известно из открытых источников (поиск по названию)
Издатель — Allstar Union (Google Play: com.allstarunion.nod), игра в сторах с ~2022, версия 1.20.x. Данные из фан-гайдов 2021–2025, местами противоречат друг другу.
- **Фракции:** вампиры, оборотни, охотники, маги; 60+ героев. Классы героев: танк, лекарь, урон, поддержка.
- **Ресурсы:** еда, дерево, вода, кристаллы (+ деньги, + премиум-алмазы — видно на скринах).
- **Здания/развитие:** ресурсные здания; исследовательский центр (ветки: развитие, войска, территория, навыки); тренировочные лагеря трёх типов войск.
