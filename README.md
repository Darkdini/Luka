# ⚔ Короны и Крепости

Браузерная средневековая стратегия. Вы отстраиваете свою крепость, собираете армию и героев и атакуете замки других игроков и логова NPC в общем мире.

## Запуск

Нужен **Node.js 22.5+** (для встроенного SQLite).

```bash
npm install
npm start            # http://localhost:3000
npm run dev          # с автоперезапуском и тестовыми покупками кристаллов
npm test             # тесты симуляции боя и экономики
node --no-warnings tools/seed_bots.js 5000   # нагрузочный тест: заселить мир ботами (только для разработки)
npm run assets       # перенарезать арт из art/source (нужны Python 3, Pillow, numpy, scipy)
```

Переменные окружения: `PORT`, `DATA_DIR` (папка с базой, по умолчанию `data/`), `SECRET` (ключ подписи токенов; если не задан, генерируется и хранится в базе), `DEV_PURCHASES=1` (начислять донат-пакеты без оплаты).

## Что уже есть

- **Аккаунты:** регистрация, вход, 4 расы с бонусами (люди, эльфы, гномы, орки).
- **Поселение:** изометрическая база на нарисованном плато, каменные фундаменты, перетаскивание зданий, стены цепочкой, расчистка препятствий.
- **Экономика:** 15 типов зданий, Цитадель на 6 уровней открывает новые здания и лимиты, строители, таймеры, ускорения за кристаллы.
- **Армия:** 9 видов войск, 5 заклинаний, кузница улучшает войска, 4 героя со способностями.
- **Бой:** высадка по краю, умный поиск пути (A*), стены ломаются, у каждого типа войск свои цели. Есть оборона (лучники, баллисты, требушеты, маги), скрытые ловушки, звёзды, добыча, кубки, щиты.
- **Античит:** симуляция детерминирована. Сервер прогоняет её заново по журналу команд игрока и сам считает итог.
- **Общий мир — континент 680×680 клеток:** ~7 000 замков с промежутком минимум 3 клетки, биомы (леса, горы, озёра, снежный север, пустынный юг, топи), ~1100 лагерей NPC — чем ближе к центру, тем сильнее. В центре — Цитадель Тёмного лорда. Рельеф генерируется одной формулой на сервере и клиенте; сервер отдаёт только замки в видимой области. Миникарта, поиск игроков, «Мой замок».
- **Профили:** аватар, лига, титул, девиз, статистика, герои, витрина достижений, «в сети/был N назад», осмотр чужого замка.
- **Достижения:** 13 достижений × 3 ступени с наградами кристаллами, титулы за золотые ступени, аватары открываются героями и достижениями. 7 лиг по кубкам, рейтинг с вашим местом.
- **Сюжет «Пепел Короны»:** 10 глав, диалоги в стиле визуальной новеллы, две развилки с последствиями, особые битвы, награды за первое прохождение и за 3 звезды; главы открываются уровнем Цитадели.
- **Социальное:** чат королевства в реальном времени, уведомления о нападениях, рейтинг, отчёты о боях.
- **Донат:** витрина кристаллов и стартового набора, покупка ресурсов, строителей и ускорений. Подробности в [docs/BALANCE.md](docs/BALANCE.md).

## Структура

```
shared/config.js   — весь баланс (здания, войска, герои, заклинания, формулы кристаллов)
shared/sim.js      — детерминированная симуляция боя (общая для клиента и сервера)
shared/worldgen.js — процедурный континент и лагеря NPC
shared/story.js    — сюжетная кампания (тексты, персонажи, развилки)
shared/achievements.js — достижения, лиги, аватары
server/            — Express + WebSocket + SQLite: аккаунты, экономика, мир, атаки
client/            — Canvas-рендер изометрии + DOM-интерфейс (без сборщика)
art/source/        — исходные AI-листы
tools/             — нарезка листов на спрайты
docs/              — баланс, монетизация, промты на графику
```
